# 🧰 FERRAMENTAS E RECURSOS - HOMENS DO REINO

## 🖼️ Compressão de Imagens (obrigatório antes do upload)
- **TinyPNG** ⭐ → https://tinypng.com (arraste, espere, baixe)
- **Squoosh** → https://squoosh.app (resize 1200px + MozJPEG q80)

## 📸 Banco de Imagens (Unsplash)
- **Método seguro (NUNCA dá 404):** link de busca → https://unsplash.com/s/photos/[termo]
- **Método atalho (pode quebrar):** link direto → https://images.unsplash.com/photo-[id]?w=1200&q=80
- **Regra:** ao encontrar a foto, teste o link direto. Se der 404, use a busca.

## 🐙 GitHub
- **Ver HTML para print:** abra o .html → botão "Raw" → tire o print.
- **Buscar arquivo:** dentro da pasta, pressione `/` e digite o termo.
- **Busca global:** `Ctrl+K` / `Cmd+K`.
- **Renomear arquivo:** abra → lápis ✏️ → mude o nome → Commit.
- **Commit:** descreva a mudança e clique no botão verde.

## 💻 Edição
- **VS Code** (recomendado) → https://code.visualstudio.com/
- Bloco de Notas / TextEdit para edições rápidas.

## 📱 Agendamento
- **Relógio ⏰ do LinkedIn** (gratuito, nativo) → agende post + hora.
- **Buffer** (opcional) → https://buffer.com
