## 🖼️ 1. Compressão de Imagens (Obrigatório antes de subir para o GitHub)
*Evita erros de carregamento (404) e deixa o site rápido.*

- **[TinyPNG](https://tinypng.com)** (⭐ Recomendado)
  - **Como usar:** Arraste a imagem para a tela, espere a barra verde de compressção e clique em "Download". 
  - **Dica:** Renomeie o arquivo baixado para o nome exato do post (ex: `filipenses-4-8.jpg`) antes de subir.
- **[Squoosh](https://squoosh.app)** (Alternativa do Google)
  - **Como usar:** Arraste a imagem. No menu à direita, em "Resize", mude a largura para `1200`. Em "Compress", escolha `MozJPEG` com qualidade `80`. Clique no ícone de download.

---

## 📸 2. Banco de Imagens Gratuitas
*Imagens de alta qualidade, livres de direitos autorais (Unsplash).*

- **[Unsplash](https://unsplash.com)**
  - **Dica de Link Direto:** Ao encontrar uma imagem, clique nela, depois no botão "Download" ou clique com o botão direito e "Copiar endereço da imagem". 
  - **Truque de URL:** Para garantir que a imagem carregue rápida e com boa qualidade no site, adicione `?w=1200&q=80` no final do link da imagem. 
    - *Exemplo:* `https://images.unsplash.com/photo-xyz?w=1200&q=80`

## 💻 3. Edição de Texto e Código
- **[Visual Studio Code (VS Code)](https://code.visualstudio.com/)** (Recomendado)
  - Software gratuito e leve para editar os arquivos `.md` e `.html` no seu computador antes de subir para o GitHub.
- **Bloco de Notas** (Windows) ou **TextEdit** (Mac)
  - Funciona perfeitamente para edições rápidas se você não quiser instalar programas.

---

## 🐙 4. Dicas de Navegação no GitHub
- **Ver o HTML puro para tirar print:** 
  1. Abra o arquivo `.html` no GitHub.
  2. Clique no botão **"Raw"** no canto superior direito do arquivo.
  3. A página ficará em branco com o código. Agora sim, tire o print da tela (Win+Shift+S ou Cmd+Shift+4).
- **Commit Changes:** Sempre que adicionar ou alterar um arquivo, role até o final da página, escreva uma breve descrição (ex: "Adicionando post Hebreus 12") e clique no botão verde **"Commit changes"**.

---

## 📱 5. Agendamento e Publicação
- **Agendador Nativo do LinkedIn:**
  - Ao criar uma publicação no LinkedIn, não clique direto em "Publicar". Clique no **ícone de relógio (⏰)** ao lado do botão. Escolha a data e hora (ex: 08:00) e clique em "Agendar".
- **Buffer (Opcional):** [buffer.com](https://buffer.com) - Ferramenta gratuita para agendar posts em até 3 canais sociais de uma vez.
